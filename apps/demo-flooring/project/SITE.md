# Site Map

- `/` — photographic slider, material overview, recent projects, process, and testimonial.
- `/about` — studio story, principles, and fictional studio facts.
- `/services` — material-service index.
- `/services/engineered-oak` — engineered oak detail.
- `/services/natural-stone` — natural stone detail.
- `/services/wool-carpet` — wool carpet detail.
- `/contact` — studio details and consultation enquiry form.

Every route uses `ProjectShell`, which composes Stardrive's document layout with project-owned Header and Footer components.
