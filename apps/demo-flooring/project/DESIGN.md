# Design

The visual direction is warm, architectural, and editorial: natural oak and limestone photography, an off-white paper background, charcoal text, and a restrained clay-brown accent.

## System

- Display typography: Georgia fallback serif for expressive headings.
- Interface typography: system sans serif for navigation, labels, and body copy.
- Geometry: square media frames, hairline borders, minimal shadow.
- Rhythm: generous section spacing with open layouts instead of repetitive cards.
- Motion: seven-second slider progression that pauses during hover/focus and disables itself for reduced-motion users.

Brand values are project-level `--wf-*` overrides in `src/styles/project.css`; shared packages remain unchanged.
