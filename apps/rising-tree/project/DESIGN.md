# Design

Retain the supplied Modern Clinical direction: deep green hero, serif headings, mint surfaces, mosaic imagery, numbered service cards and portrait cards.

Project > Theme > Template > Shared remains the resolution model. The theme changes semantic colours, fonts, radius and spacing; the template owns responsive grids and section markup. Project assets and all editorial copy remain here.

The original 19 suggested modules are represented by ten section components with bounded variants. Navigation and footer are component-registry entries. The document shell and SEO reuse shared packages.

Accessibility improvements: skip link, one H1 per page, keyboard focus styles, labelled menu with expanded state and Escape support, native details/summary FAQ, reduced-motion support, labelled required form fields and live submission feedback, and a single-column narrow-screen content layout.

Technical prototype copy was removed from public descriptions; supplied professional claims were not expanded or reinterpreted. The project contact override fills the template form slot with the shared form component. Missing configuration and provider failures show explicit feedback.
